01 Aceitação dos Termos

Ao adicionar a Evandel Bot ao seu servidor do Discord ou utilizar seus comandos, você concorda com estes Termos de Serviço. Se não concordar, remova a bot de imediato.

02 Descrição do Serviço

A Evandel é uma bot de entretenimento para Discord, oferecendo:

  • Chat com inteligência artificial (Groq / llama-3.3-70b)
  • Reprodução de música via voz (YouTube, Jamendo, iTunes)
  • Comandos de moderação e utilidade
  • Modo 24/7 em canais de voz

03 Uso Aceitável

Ao utilizar a bot, você concorda em:

  • Não usar a bot para assédio, spam ou conteúdo ilegal
  • Não tentar explorar, sobrecarregar ou manipular a bot
  • Não usar a bot para violar os Termos de Serviço do Discord
  • Não redistribuir ou revender o serviço da bot

04 Coleta e Uso de Dados

A Evandel coleta apenas os dados estritamente necessários para funcionar:

  • ID do usuário — para responder a comandos
  • ID do servidor e canais — para gerenciar voz e permissões
  • Conteúdo de mensagens — apenas quando a bot é mencionada ou um comando é usado

Nenhum dado pessoal é armazenado permanentemente, vendido ou compartilhado com terceiros.
