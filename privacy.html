Política de Privacidade

Última atualização: 16 de agosto de 2026

01 Introdução

A presente Política de Privacidade descreve como a Evandel Bot coleta, usa e protege dados ao operar dentro de servidores do Discord. Ao adicionar ou interagir com a bot, você concorda com as práticas descritas aqui.

02 Dados Coletados

A Evandel coleta apenas os dados estritamente necessários para seu funcionamento:

  • ID do usuário — identificador único do Discord, usado para responder a comandos e gerenciar permissões
  • ID do servidor e canais — para operar em canais de voz e garantir que comandos funcionem no contexto correto
  • Conteúdo de mensagens — processado apenas quando a bot é mencionada ou quando um comando é ativado
  • Dados de áudio temporários — durante reprodução em canais de voz, áudio é processado em tempo real e não é armazenado

03 Dados NÃO Coletados

A Evandel não coleta:

  • Nomes, e-mails ou informações pessoais fora do Discord
  • Histórico completo de mensagens do servidor
  • IPs, localizações ou dados de dispositivos
  • Dados de pagamento ou informações financeiras
  • Cookies ou identificadores de rastreamento

04 Uso dos Dados

Os dados coletados são utilizados exclusivamente para:

  • Processar e responder a comandos enviados pelo usuário
  • Gerenciar conexões em canais de voz
  • Manter o funcionamento adequado da bot

Os dados não são usados para publicidade, análise comportamental ou qualquer finalidade comercial.

05 Armazenamento e Retenção

A Evandel não armazena dados permanentemente. Todo processamento ocorre em tempo e os dados são descartados imediatamente após o uso. Músicas baixadas temporariamente (via YouTube) são removidas do disco após cada reprodução.

06 Compartilhamento com Terceiros

Os dados da Evandel não são vendidos, compartilhados ou transmitidos a terceiros, exceto nos seguintes casos:

  • API da Groq — mensagens mencionando a bot são enviadas à API de IA para gerar respostas. A Groq possui sua própria política de privacidade
  • YouTube / Jamendo / iTunes — buscas por músicas são feitas diretamente, sem enviar dados pessoais do usuário
  • Exigência legal — em caso de ordem judicial ou obrigação legal

07 Segurança

A Evandel utiliza práticas básicas de segurança:

  • Tokens e chaves de API são armazenados em variáveis de ambiente (não no código)
  • Conexões com a API do Discord utilizam HTTPS
  • Nenhum dado sensível é registrado em logs

08 Direitos do Usuário

Como usuário, você tem direito a:

  • Remover a bot do servidor a qualquer momento — todos os dados associados são descartados imediatamente
  • Solicitar esclarecimentos sobre quais dados são processados
  • Interromper a interação simplesmente deixando de mencionar a bot ou usar seus comandos

09 Menções e Chat com IA

Quando você menciona a Evandel ou envia um comando, o conteúdo da mensagem é enviado à API da Groq para gerar uma resposta. Essa mensagem:

  • É processada uma única vez e descartada
  • Não é armazenada em banco de dados
  • Não é associada ao seu perfil de forma permanente

Recomenda-se não enviar dados pessoais sensíveis em mensagens destinadas à bot.

10 Serviços de Terceiros

A Evandel utiliza serviços externos que possuem suas próprias políticas de privacidade:

  • Discord — Política de Privacidade
  • Groq — Política de Privacidade
  • Jamendo — Termos e Privacidade

11 Alterações nesta Política

Esta política pode ser atualizada a qualquer momento. Alterações significativas serão comunicadas no servidor de suporte da bot, quando disponível.

12 Contato

Em caso de dúvidas sobre privacidade ou dados, entre em contato pelo servidor de suporte do Discord ou abra uma issue no GitHub.
